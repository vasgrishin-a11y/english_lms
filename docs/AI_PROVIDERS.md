# ИИ-провайдеры: чем заменить Gemini из России

Ключ Google Gemini получить и использовать из РФ нельзя: Gemini API не входит в список
поддерживаемых регионов, запросы с российских IP отклоняются, а российские карты Google
не принимает. Ниже — бесплатные варианты, которые реально работают из России, и то, как
каждый из них подключить к ИИ-помощнику (`lms/ai.py`).

Провайдер выбирается одной переменной окружения `LMS_AI_PROVIDER`; код помощника при
смене провайдера не меняется. Если ключа нет — помощник не отключается, а разбирает
материал офлайн-эвристиками (DOCX, XLSX, PDF, TXT/MD/CSV).

## Короткий вывод

| Задача | Что выбрать | Бесплатно? | Работает из РФ без VPN? | Читает фото/PDF? |
| --- | --- | --- | --- | --- |
| **По умолчанию для школы** | **GigaChat (Сбер)** — `LMS_AI_PROVIDER=gigachat` | да, Freemium для физлиц | да | да (фото, PDF) |
| Только текст, много запросов | Yandex AI Studio (YandexGPT) — `yandex` | стартовый грант Yandex Cloud | да | нет |
| Зарубежные модели с оплатой картой РФ | ProxyAPI / VseGPT / AITUNNEL — `proxyapi`, `vsegpt`, `aitunnel` | нет (пробные квоты) | да | зависит от модели |
| Совсем без облака | Ollama или LM Studio на своём сервере — `ollama` | да, навсегда | да (свой сервер) | зависит от модели |
| Как было раньше | Google Gemini — `gemini` | да | нет (нужен VPN) | да |

## Варианты подробно

### 1. GigaChat (Сбер) — рекомендуется по умолчанию

- **Бесплатный тариф.** Режим Freemium для физлиц: годовая квота токенов, без карты и без
  договора (лимиты и состав квоты Сбер периодически меняет — сверяйтесь со страницей тарифов
  `developers.sber.ru/docs/ru/gigachat`). Ограничения Freemium: один поток запросов (1 RPS) и
  квота раз в 12 месяцев. Для подготовки материалов преподавателем этого достаточно.
- **Доступность.** Серверы в РФ, регистрация по Сбер ID, оплата рублями, если квота кончится.
- **Мультимодальность.** Читает изображения и PDF: файл загружается в хранилище GigaChat и
  передаётся вложением (реализовано в `_gigachat_attachment`). DOCX/XLSX/TXT и так разбираются
  офлайн и уходят промптом.
- **Нюанс TLS.** GigaChat отдаёт сертификат НУЦ Минцифры, которого нет в стандартных хранилищах
  Python. Скачайте корневой сертификат и укажите путь:

  ```bash
  curl -k "https://gu-st.ru/content/Other/doc/russian_trusted_root_ca.cer" \
       -o /app/var/russian_trusted_root_ca.pem
  # LMS_AI_CA_BUNDLE=/app/var/russian_trusted_root_ca.pem
  ```

  `LMS_AI_VERIFY_SSL=0` отключает проверку TLS целиком — только как временная мера: без проверки
  сертификата ключ авторизации можно перехватить (MITM).
- **Настройка:**

  ```dotenv
  LMS_AI_ENABLED=1
  LMS_AI_PROVIDER=gigachat
  LMS_AI_API_KEY=<ключ авторизации из личного кабинета GigaChat API>
  # Модель и адрес можно не задавать: GigaChat-2 и https://api.giga.chat/v1
  LMS_AI_CA_BUNDLE=/app/var/russian_trusted_root_ca.pem
  ```

  Для юрлица тот же адаптер работает через `LMS_AI_SCOPE=GIGACHAT_API_B2B` (или `_CORP`)
  и при необходимости `LMS_AI_AUTH_ENDPOINT`.

### 2. Yandex AI Studio (YandexGPT) — текст, стартовый грант

- OpenAI-совместимый эндпоинт `https://ai.api.cloud.yandex.net/v1`, авторизация — `Api-Key`
  сервисного аккаунта, модель указывается как `gpt://<folder_id>/yandexgpt-5.1`.
- Данные в РФ, 152-ФЗ; новым платёжным аккаунтам Yandex Cloud даёт стартовый грант — на нём
  можно отработать пилот. Дальше — оплата за токены по рублям.
- Фото страницы учебника не читает: для картинок нужен другой провайдер (`LMS_AI_UPLOAD_KINDS`
  у пресета пуст, помощник честно скажет об этом и разберёт текст).

```dotenv
LMS_AI_PROVIDER=yandex
LMS_AI_API_KEY=<Api-Key сервисного аккаунта>
LMS_AI_MODEL=gpt://<folder_id>/yandexgpt-5.1
```

### 3. Российские шлюзы к зарубежным моделям: ProxyAPI, VseGPT, AITUNNEL

- Те же модели, что у OpenAI/Gemini/Anthropic, но доступ идёт через российский посредник:
  без VPN, оплата картой РФ, у части сервисов есть договор и закрывающие документы.
- Бесплатного тарифа, как правило, нет — только пробные суммы; для школы это осознанное
  решение «платим немного за качество».
- Подключение то же, что у любого OpenAI-совместимого шлюза:

  ```dotenv
  LMS_AI_PROVIDER=proxyapi      # или vsegpt, aitunnel, openrouter
  LMS_AI_API_KEY=<ключ шлюза>
  LMS_AI_MODEL=<модель из каталога шлюза>
  # LMS_AI_ENDPOINT=https://api.proxyapi.ru/openai/v1  # адрес пресета, можно переопределить
  ```

- **OpenRouter** отдельно: у него есть бесплатные модели с суффиксом `:free` (суточные лимиты
  запросов), но регистрация из РФ проходит не всегда, а часть моделей блокирует российские IP.
  Как основной вариант для школы он ненадёжен, как запасной — годится.

### 4. Локальные модели: Ollama, LM Studio — бесплатно навсегда

- Модель работает на своём сервере (VPS или школьная машина), данные никуда не уходят —
  это самый безопасный с точки зрения 152-ФЗ вариант, но нужны ресурсы: 8–16 ГБ RAM для
  моделей уровня 7B, для vision-моделей (Qwen-VL, Gemma 3) — больше.
- Ollama отдаёт OpenAI-совместимый API по `http://localhost:11434/v1`.

  ```dotenv
  LMS_AI_PROVIDER=ollama
  LMS_AI_API_KEY=local            # ключ не нужен, но помощник включается по непустому значению
  LMS_AI_MODEL=qwen3:8b           # любая установленная модель
  LMS_AI_JSON_MODE=0              # response_format json_object поддерживают не все модели
  ```

### 5. DeepSeek и Qwen (Китай)

- Оба доступны из РФ без VPN. DeepSeek: очень дешёвый текст, бесплатного тарифа API нет
  (есть бесплатный веб-чат). Qwen через Alibaba DashScope: новым аккаунтам дают бесплатную
  квоту, есть vision-модели Qwen-VL.

  ```dotenv
  LMS_AI_PROVIDER=deepseek        # или qwen
  LMS_AI_API_KEY=<ключ>
  LMS_AI_MODEL=deepseek-chat      # модель из каталога провайдера
  ```

### 6. Любой свой шлюз (self-hosted, корпоративный прокси)

Незнакомое значение `LMS_AI_PROVIDER` не ошибка: такой провайдер считается
OpenAI-совместимым. Достаточно указать адрес:

```dotenv
LMS_AI_PROVIDER=my-gateway
LMS_AI_ENDPOINT=https://ai.example.ru/v1
LMS_AI_API_KEY=<ключ>
LMS_AI_MODEL=<модель>
```

### 7. Gemini (если появится доступ)

Поддержка сохранена: `LMS_AI_PROVIDER=gemini` + `LMS_AI_API_KEY`. Это единственный из
перечисленных адаптеров, который понимает видео и аудио; из РФ требует VPN и зарубежный
аккаунт, поэтому по умолчанию больше не используется. Если в `.env` осталась модель
`gemini-2.0-flash`, а провайдер уже другой, помощник возьмёт модель нового провайдера и
напишет предупреждение в журнал.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `LMS_AI_ENABLED` | `1` | Окно помощника; `0` выключает его целиком |
| `LMS_AI_PROVIDER` | `gigachat` | `gigachat`, `yandex`, `proxyapi`, `vsegpt`, `aitunnel`, `openrouter`, `deepseek`, `qwen`, `ollama`, `gemini`, `openai` или своё имя |
| `LMS_AI_API_KEY` | пусто | Ключ провайдера. Пусто — офлайн-разбор без сети |
| `LMS_AI_MODEL` | модель провайдера | Например, `GigaChat-2`, `gpt://<folder>/yandexgpt-5.1`, `qwen3:8b` |
| `LMS_AI_ENDPOINT` | адрес провайдера | Переопределение базового адреса API |
| `LMS_AI_AUTH_ENDPOINT`, `LMS_AI_SCOPE` | значения для физлица GigaChat | Доступ юрлица (B2B/CORP) |
| `LMS_AI_CA_BUNDLE` | пусто | Путь к корневому сертификату НУЦ Минцифры |
| `LMS_AI_VERIFY_SSL` | `1` | `0` — отключить проверку TLS (не рекомендуется) |
| `LMS_AI_JSON_MODE` | `1` | `response_format=json_object` для OpenAI-совместимых шлюзов |
| `LMS_AI_UPLOAD_KINDS` | возможности провайдера | Что отправлять вложением: `image,pdf,video,audio`, `none` |
| `LMS_AI_TIMEOUT`, `LMS_AI_MAX_*` | см. `.env.production.example` | Таймаут, размер файла и лимиты структуры |

## Ограничения, о которых нужно знать

- **Персональные данные.** Материалы преподавателя уходят третьей стороне. Работы учеников в
  помощник не отправляются, но при выборе облачного провайдера нужен договор/DPA и решение
  школы; локальный Ollama — вариант «без облака».
- **Бесплатные квоты меняются.** Сбер и Яндекс регулярно пересматривают лимиты и модели.
  Проверяйте актуальные тарифы перед пилотом; в коде значения не зашиты — всё в окружении.
- **Качество на английском.** Для генерации заданий по английскому языку GigaChat-2 и
  YandexGPT работают приемлемо, но формулировки всегда проверяет преподаватель: помощник
  создаёт только черновики.
- **1 RPS у GigaChat Freemium.** Один поток запросов: одновременная работа нескольких
  преподавателей может упираться в лимит — тогда нужен платный пакет или второй провайдер.

## Проверка настроек

```bash
python manage.py ai_check            # покажет режим, провайдера, модель, адрес и вложения
python manage.py ai_check --live     # отправит один пробный материал и покажет счётчики черновика
```

Команда без `--live` работает без сети и ничего не импортирует: это безопасный способ
убедиться, что площадка видит нужные переменные. `--live` делает ровно один запрос к
провайдеру (ключ и сертификат на месте), черновики не создаются.

## Что менять в коде при добавлении нового провайдера

Обычно — ничего: добавьте имя и адрес в `PROVIDERS` (`lms/ai.py`) либо задайте
`LMS_AI_PROVIDER` + `LMS_AI_ENDPOINT`. Отдельный адаптер (`kind`) нужен только если у
провайдера собственный протокол, как у Gemini (`generateContent`) или GigaChat (OAuth,
вложения). Тесты нового адаптера — в `lms/tests/test_ai.py`, сеть там не используется:
транспорт подменяется классом `FakeTransport`.
